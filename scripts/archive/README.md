# Archived experiment scripts

These scripts are preserved for reproducing and auditing historical experiment outputs. They are not active entry points for new experiments.

- `analyze_002_trajectories.py` — historical Experiment 002 analysis
- `analyze_cap_sensitivity.py` — historical Experiment 001 cap analysis
- `summarize_001_depth_scaling.py` — historical Experiment 001 summarization
- `train_003_predictors.py` — historical Experiment 003 predictor training
- `train_004a.py` — historical Experiment 004A training
- `train_004b.py` — historical Experiment 004B training
- `diagnose_004a.py` — historical Experiment 004A diagnostics

The files remain unchanged from their pre-archive versions. Do not use them for new scientific claims without an explicit audit protocol and fresh output paths. Active shared model and correctness code lives under `src/`.
