# Experiment 002: Recurrent trajectory analysis

Measurement-only analysis of Huginn recurrent-core states. The experiment
captures `h0...h64` for 50 fixed GSM8K prompts and measures convergence,
normalized step size, update-direction geometry, and update-subspace
concentration. It does not train a predictor or implement Attention².

The frozen result is summarized in `results/002_trajectory_analysis/conclusion.md`.
